TRADING AI ANALYZER — ENG OSON ISHGA TUSHIRISH

1. ZIP faylni yuklab oling.
2. ZIP fayl ustiga o'ng tugma bosing va Extract All (Barchasini chiqarish) ni tanlang.
3. Chiqarilgan trading-ai papkasini oching.
4. run.bat faylini ikki marta bosing.
5. Birinchi ishga tushishda Python kutubxonalari internet orqali o'rnatiladi.
6. Terminal so'raganda OpenAI API kalitingizni o'zingiz kiriting.

- Windows kompyuterda Python 3.12 tavsiya etiladi.
- OpenAI API kaliti. Kalitingizni hech kimga yubormang va HTML/Python fayllar ichiga yozmang.
- OpenAI API ishlatish hisobingizda alohida to'lov talab qilishi mumkin.
